# 核心依赖（必需——缺少则应用无法启动）

# S2-9：**每个依赖都声明上限**（`<下一个大版本`）。理由不是洁癖，而是这个项目的
# 实际形状：`environment.lock.yml` 只在有人跑 `make lock-env` 时更新，而 CI 安装的是
# **本文件**（浮动）。没有上限时，某个依赖发大版本会在 CI 里静默换掉实现——
# 本地（按锁）与 CI（按本文件）跑的是两套代码，而门禁只保证"锁里有 pin"。
# 上限只设在**已知会破坏**的大版本处（pydantic 2→3、aiohttp 3→4、httpx 0.x→1.0
# 这类 API 断代），不是随手写 `<999`：`check_env_lock.py` 会校验锁满足这些声明，
# 抬上限/换大版本时锁不同步就会红。
