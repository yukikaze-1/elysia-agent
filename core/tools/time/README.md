# 时间工具插件

> 文档导航：[项目文档](../../../README.md)

获取当前日期和时间，支持多时区和格式。

## 工具

- `get_time` — 获取当前时间。参数：`timezone`（默认 `"UTC"`，支持 `"Asia/Shanghai"`、`"+8"` 等）、`format`（`"iso"` 或 `"human"`）。

## 配置 (config.yaml)

无需特殊安全配置，使用 SafetyProfile 默认值。
